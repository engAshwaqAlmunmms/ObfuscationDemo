# ObfuscationDemo

A simple iOS project created to explore and understand code obfuscation and application security techniques.

## Objectives
- Understand how iOS binaries can be analyzed.
- Explore Swift code obfuscation techniques.
- Learn how string encryption and symbol obfuscation work.
- Evaluate the impact of obfuscation on app functionality.

## Tools
- Xcode
- Swift
- SwiftyShield
- LLVM

## Topics Covered
- Name Obfuscation
- String Encryption
- Symbol Stripping
- Binary Analysis

## Notes
This project is for learning and experimentation purposes only.
